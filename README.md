# 해양기상 종합 관측 대시보드 (Marine Weather Live)

대한민국 전 연안 및 외해의 해양기상 정보를 실시간으로 모니터링할 수 있는 고성능 반응형 대시보드입니다.

## 🌊 주요 기능
- **멀티 프로바이더 관측망 통합 (200개소)**:
  - **기상청(KMA) 해양기상부이 17개소**: 덕적도, 칠발도, 거문도, 거제도, 동해, 포항, 마라도 등 실시간 **유의파고(Significant Wave Height)**, **최대파고**, **파주기**, **파향** 관측
  - **국립해양조사원(KHOA) 7개소**: 주요 조위관측소 및 해양관측부이
  - **국립해양측위정보원(NMPNT) 176개소**: 전국 유인/무인 등대 및 항로표지 기상신호표지
- **실시간 풍향/풍속 나침반 & 계측 게이지**: 16방위 풍향 나침반 및 보포트 풍급 자동 판별
- **해양 환경 지표**: 해수 수온, 대기 기온, 해면 기압, 습도, 시정, 염분/조위
- **24시간 관측 추이 시계열 차트 (Chart.js)**: 풍속, 파고(m), 수온/기온, 기압 인터랙티브 그래프
- **CSV 내보내기**: 관측 데이터 원클릭 CSV 다운로드
- **고해상도 다크 테마 지도**: ESRI Dark Gray Canvas 기반의 매끄러운 시각화

## 🚀 빠른 시작 (Local)
```bash
python server.py
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

## ☁️ 클라우드 배포 (Render / Cloud Platforms)
- **Start Command**: `python server.py`
- **Environment Variable**: `PORT=8080` (자동 감지)
- 별도의 pip 패키지 설치 없이 Python 3.10+ 환경에서 즉시 구동됩니다.
